# History

These pages are records of how earlier builds of sql-megasamples were upgraded, rehearsed and
checked: evidence pages, review receipts and the coordinator's live-upgrade runbook. They are not
user documentation, and they describe the project as it was on the dates they carry. They may use
internal reference codes (decision, review and task numbers) that mean nothing outside the
project's own records.

Some tests and scripts still read them, which is why they are kept here rather than deleted.
For how to use the servers, read the [README](../../README.md) and the
[release notes](../release-notes.md).

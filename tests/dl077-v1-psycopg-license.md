# T-28 Psycopg dependency licence review

Psycopg 3.3.9 is distributed under LGPL-3.0-only. The selected distribution is the pure Python `psycopg` package. It is imported at runtime as a separately installed, replaceable library. It loads the operating system's libpq. The project's own code is Apache-2.0 (`LICENSE`, `LICENSES.md`), and keeps that licence while declaring this dependency: the wheel names Psycopg as a requirement and carries none of its code. [Release metadata](https://pypi.org/project/psycopg/3.3.9/), [installation instructions at 3.3.9](https://raw.githubusercontent.com/psycopg/psycopg/3.3.9/docs/basic/install.rst), both read 2026-11-21 03:53 UTC.

The application's wheel can declare the dependency without conveying a copy of the library. If a distributor ships a combined work with the library, LGPL section 4 requires notice, the GPL and LGPL licence texts, and terms that permit modification of the library and reverse engineering to debug those modifications. It also requires a replaceable library mechanism or the materials to relink, plus any applicable installation information. Redistribution of the library itself has the corresponding source requirements of the LGPL and GPL. The runtime dependency is suitable on the separate-install route. [Licence at 3.3.9](https://raw.githubusercontent.com/psycopg/psycopg/3.3.9/LICENSE.txt), read 2026-11-21 03:53 UTC.
